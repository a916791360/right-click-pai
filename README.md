# 右键派

</p>

一个开源、轻量的原生 macOS Finder 右键工具。右键派只做五件事，并且每项功能都可以独立开启或关闭。

## 功能

- **拷贝路径**：复制所选文件或文件夹的绝对路径；多选时每行一个。
- **移动到**：为所选文件或文件夹选择目标文件夹并立即移动；遇到同名项目时不会覆盖。
- **隐藏已选项目**：使用 macOS 原生隐藏标记隐藏文件或文件夹，不移动、不改名、不删除。
- **取消隐藏当前文件夹内全部项目**：在 Finder 文件夹空白处右键，恢复当前层被隐藏的普通项目。
- **进入终端**：选中文件夹或文件后直接打开“终端”并进入对应目录，不用再把文件夹拖进终端。

关闭 App 中的某个开关后，对应动作会从 Finder 右键菜单中消失。

## 下载和安装

从 [Releases](https://github.com/a916791360/right-click-pai/releases/latest) 下载最新的 `RightClickPai-v1.4.0-Apple-Silicon.zip`，解压后将 `右键派.app` 拖入“应用程序”文件夹。

详细安装步骤、系统要求、使用说明、隐私说明、从源码构建方法，见 [V1.4.0/README.md](V1.4.0/README.md)。

## 系统要求

- Apple Silicon Mac（M1 及以上）
- macOS 15 或更高版本
